# 🔍 Generative Data Augmentation Framework for Wi-Fi Gesture Recognization

> 🌟 This repository is the official source code from the paper of 	``Generative AI for Data Augmentation in Wireless Networks: Analysis, Applications, and Case Study.`` Welcome to see our work on arXiv.


## 🎯 Overview
This paper systematically explores the potential and effectiveness of generative data augmentation in wireless networks. To evaluate the effectiveness of generative data augmentation, we propose a generative data augmentation framework for Wi-Fi gesture recognition, which is a general tutorial.


## 🛠️ Technical Stack
- 📝 Datasets: Widar 3.0
- 🤖 GenAI models: Transformer-based diffusion model
- 🗄️ DNN models: ResNet

## 👣 Procedure
Step 1: Run Generate_test to convert the CSI data from the dat type to the mat type.

Step 2: Take the converted CSI data as cond and use the transformer-based diffusion model to synthesize new data.
